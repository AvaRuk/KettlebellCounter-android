# 📱 Kettlebell Counter · Android

**Приложение для судей и хронометриста: пульт табло для гиревого спорта, которым управляют кнопки громкости телефона**

`Android 10+` · `WebView` · `Kotlin`

---

## Что это

Приложение-оболочка для сервера табло **Kettlebell Counter** (отдельный проект на Node.js). Внутри — обычный `WebView`, который открывает страницы сервера. Зачем оно нужно: страница в браузере не видит кнопки громкости телефона, а приложение их перехватывает и передаёт странице. Так счёт и таймер можно вести, не глядя в экран.

Приложение само ничего не считает: всё состояние хранится на сервере, а приложение только показывает его страницы.

## Как пользоваться

1. Запустите сервер табло на компьютере. Телефон должен быть в той же сети (Wi-Fi или точка доступа). Интернет не нужен.
2. Откройте приложение и введите адрес сервера с портом, например `192.168.1.10:8080`. Если порт не указан, используется 80. Адрес запоминается.
3. Откроется страница входа. Введите PIN: сервер сам определит роль и откроет нужный пульт.
4. Ведите счёт или управляйте таймером кнопками громкости.

### Кнопки громкости

| PIN | Пульт | Громкость вверх | Громкость вниз |
|---|---|---|---|
| судьи команды | счётчик команды | +1 к счёту | −1 к счёту |
| хронометриста | таймер | старт / пауза | сброс таймера |
| администратора | админ-панель | — | — |

Системная громкость при этом не меняется. Сброс таймера работает, только когда таймер не идёт (это правило сервера). Кнопки действуют, пока приложение открыто на экране; экран не гаснет.

### Смена адреса и выход

На экране нет заголовка и строки состояния: приложение занимает весь экран (строка состояния ненадолго появляется при свайпе от верхнего края). Чтобы сменить адрес сервера, нажмите «Назад» на первой странице: появится меню **«Обновить / Сменить адрес сервера / Выйти»**. На внутренних страницах «Назад» возвращает по истории страниц.

Если сервер недоступен (неверный адрес, сервер выключен, нет Wi-Fi), приложение само возвращается на экран ввода адреса и пишет причину.

## Сборка и установка

Нужны [Android Studio](https://developer.android.com/studio) и Android SDK 37 (компонент подтянется при синхронизации проекта).

1. Откройте папку проекта в Android Studio и дождитесь синхронизации Gradle.
2. Соберите APK: `Build → Build APK(s)` или из консоли:

   ```bash
   ./gradlew assembleDebug
   ```

   Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.
3. Перенесите APK на телефон и установите (разрешите установку из неизвестных источников). Либо запустите приложение на подключённом телефоне прямо из Android Studio кнопкой «Run».

Для выпускной сборки (`assembleRelease`) APK нужно подписать своим ключом: `Build → Generate Signed Bundle / APK`.

## Технические детали

- Минимальная версия Android: 10 (API 29), целевая: API 37.
- Права: только `INTERNET`. Сервер работает по обычному `http` в локальной сети, поэтому в манифесте включён `usesCleartextTraffic`.
- Адрес сервера хранится в `SharedPreferences` (файл `kb`, ключ `server`). Приложение открывает `http://<адрес>/`, а PIN запоминает сама страница в `localStorage` (для этого включён `domStorageEnabled`).
- Кнопки громкости перехватываются в `dispatchKeyEvent` и вызывают на странице `window.onVolume('up' | 'down')`. Эта функция объявлена в страницах сервера: `sites/controller/index.js` (счётчик) и `sites/timer/index.js` (таймер). Без неё нажатия ни на что не влияют, поэтому приложению нужна версия сервера, где они есть.
- Если при загрузке главной страницы произошла ошибка, показывается экран ввода адреса.
